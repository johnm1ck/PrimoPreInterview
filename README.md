Merge two ascending integer arrays and one descending integer array into a new ascending array. Inputs must contain finite integers in the specified order. The inputs are not modified. For n total elements, the algorithm takes O(n) time and O(n) space for the result.

## Setup and execution

Install Node.js and npm, then run:

```sh
npm install
npm start  # Build and run the example
npm test   # Run unit tests
```
